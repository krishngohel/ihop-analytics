Set it up in five minutes

No terminal, no config files. Install, open, and paste your Rosnet sign-in once.

  1. Install it

    Open the downloaded IHOP-Operations.dmg and drag IHOP Operations onto the Applications folder. Open it from Applications (or Launchpad).

  2. Allow it to open

    Because the app isn't from the Mac App Store, macOS asks before opening it. Open System Settings → Privacy & Security, scroll down, and click Open Anyway. (Or right-click the app and choose Open.)

    To stop macOS asking every time you open it, run this one command once. Open Terminal (press ⌘Space, type Terminal, Enter), paste the line below, and press Enter:

    xattr -dr com.apple.quarantine "/Applications/IHOP Operations.app"

    That command just clears the "downloaded from the internet" flag on this one app, so it opens straight away from then on. You run it once, after installing.

  3. It opens in your browser

    The dashboard opens at localhost:4000. There's no account to create and no password to remember. Look for the small pancake icon in your menu bar (top-right) — that's the app running; click it any time to reopen the dashboard, or to quit.

  4. Connect Rosnet

    Go to Data and refresh → Connections, find Rosnet portal sign-in, and enter:

    • Portal username — the email you use to sign in at portal.rosnet.com
    • Portal password — the same password
    • Client code — e.g. ACGTX (only if your login has more than one)

    Press Test connection to check it, then Save and load data. Your restaurants, sales, labor, forecasts and weather load within a minute.

    The password is stored encrypted on your Mac and never shown again. The app never posts anything back to Rosnet — it only reads reports.

  5. That's it — it keeps itself current

    The dashboard refreshes on its own: a full update at 5:30 am each day, and live sales every 15 minutes while restaurants are open. Leave the app running (it lives in the menu bar) and it stays up to date.

Good to know

  • Keep the Mac on for the morning update. The 5:30 am refresh only runs while the app is running. On the icon's menu, turn on Start When I Log In, and use a Mac that stays powered on for the team to rely on it.
  • Share it with the office. By default only this Mac can open the dashboard. Choose Let Others on This Network Open It from the menu-bar icon, and colleagues can reach it at http://<this-Mac's-name>:4000.
  • Your data stays on your Mac. Everything lives in a local folder, separate from the app — so updates never touch it. Installing a newer version keeps your data and sign-in.
  • Guest ratings come from Merchant Centric STARS, a separate system. Connect it (or a reports mailbox) under Connections to fill that section.
  • No API key needed. The portal sign-in is the quick route. If Rosnet later issues an API key (api@rosnet.com), you can switch to it under Connections.
